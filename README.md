# Sesli Kontrol - Windows sürümü

iPhone programının (dal `surum-4`, 885ddbc) Windows karşılığı. Program `SesliKontrol_Windows/` klasöründedir; kullanım için
`SesliKontrol_Windows/KULLANIM.txt` dosyasına bakın. `testler/` birim sınamalarını ve gerçek Windows'ta çalışan duman sınamasını,
`araclar/istem_cikar.py` Gemini talimatlarını iPhone kaynağından aynen aktaran betiği içerir.
